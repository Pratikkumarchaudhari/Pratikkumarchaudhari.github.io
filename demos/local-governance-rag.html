Know what the evaluation measures

Source hit rate checks whether an expected document appears among the retrieved passages. It does not establish generated answer accuracy. The eight-question evaluation is too small to support broader quality claims. BM25 scores are not probabilities or cosine similarities.

For the full RAG flow, clone the repository and follow its Windows instructions. Semantic retrieval and local generation were not rerun in this build environment. The current checks cover the keyword baseline and nine dependency-free tests.

Fictional educational content. No confidential employer documents. Local model generation requires the owner's computer; no paid inference API is used.
