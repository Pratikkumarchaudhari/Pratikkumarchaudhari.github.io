# Pratikkumar Chaudhari — Data Governance, Analytics & AI Portfolio

[Open the published portfolio](https://pratikkumar-data-ai-portfolio.woollydog11.chatgpt.site) · [LinkedIn](https://www.linkedin.com/in/pratikkumarchaudhari/)

Static HTML/CSS/JavaScript portfolio containing professional background, education, two analytics case studies, two AI learning case studies, and four interactive demonstrations. No paid API, account registration, database, or server is required by this code.

## Preview locally

Open `index.html` in a browser. All demos also work as standalone HTML files. Browser question retrieval is a BM25 baseline, not hosted LLM generation. The full local RAG project is linked from the site.

## Optional GitHub Pages hosting

The published portfolio above is available through Sites. To also use this repository on GitHub Pages, the owner can select **Settings → Pages → Deploy from a branch → main → /(root)**. Pages configuration is not exposed through the connected GitHub tools and was not changed by this build. The expected GitHub Pages URL is not claimed as live until that setting is enabled and its deployment succeeds.
