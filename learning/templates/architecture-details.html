A · Prepare the knowledge collection / indexing

01 / Load and prepare

Documents & metadata

  • PDF, text, DOCX, HTML
  • Tables, databases, APIs
  • OCR for scanned content
  • Preserve headings and units
  • Remove noise and duplicates
  • Source ID, page, version
  • Access and effective-date metadata

Project: local sample documents

02 / Split

Chunking methods

  • Fixed characters or tokens
  • Recursive splitting
  • Sentence boundaries
  • Paragraphs / headings
  • Semantic boundaries
  • Structure-aware: tables / code
  • Parent-child chunks

Tune: size, overlap, boundary rules

Project: 600 characters
100-character overlap · step 500

03 / Represent

Embedding choices

  • Dense: learned fixed-length vectors
  • Sparse: term weights / learned sparse
  • Multi-vector representations
  • Multimodal: supported text / image

Keep query/document encoders compatible. Track model version, dimensions, normalization and input limits.

Project: MiniLM-L6-v2
384-dimensional normalized dense vectors

04 / Store and index

Store ≠ metric ≠ index

  • Dedicated: Chroma, Qdrant
  • Dedicated: Milvus, Weaviate
  • Relational: PostgreSQL + pgvector
  • Search engine: Elasticsearch
  • Managed service: Pinecone
  • Library: FAISS (not a full database)

Metrics: cosine, dot product, Euclidean
Indexes: exact, HNSW, IVF; PQ for compression

Project: persistent local Chroma
HNSW · cosine distance

B · Answer a question / runtime

05 / Understand the query

Question & eligibility

  • Original user question
  • Resolve conversational context
  • Optional query rewriting
  • Multi-query / subquestions
  • Optional HyDE search representation
  • Apply user / version eligibility
  • Compatible query embedding

Project: embed the question
No agentic query planner

06 / Retrieve and refine

Evidence candidates

  • Lexical: keyword / BM25
  • Dense semantic search
  • Hybrid; combine ranks with RRF
  • Alternatives: SQL / graph retrieval
  • Parent-document retrieval
  • Rerank: cross-encoder
  • Diversity: MMR · deduplicate

Tune candidate depth, top-k and threshold. Scores are not probabilities.

Project: top 3 cosine candidates
Similarity cutoff 0.25; no reranker

07 / Augment

Assemble the context

  • Instructions + user question
  • Selected authorized passages
  • Source IDs and location references
  • Document versions / dates
  • Deduplicate / compress carefully
  • Respect context-token budget
  • Treat retrieved text as untrusted

Project: source context + question
Insufficient evidence can stop generation

08 / Generate and check

Answer with evidence

  • Local or remotely served LLM
  • Grounded answer and citations
  • Abstain / clarify if unsupported
  • Check claim-to-source support
  • Evaluate correctness separately
  • Measure latency and failures

Project: Ollama / Qwen2.5:1.5b
Public Q&A demo is extractive,
not hosted local-model generation
